# Working rules for Don Coupe (SiteSprintPro)

## Design choices go through the visual companion
For any design, layout, motion or visual decision, use superpowers:brainstorming with its visual companion:
show 2 to 4 multiple-choice visual examples (real renders, not descriptions), let Don pick, then build.
In Cowork the localhost companion server is not reachable from Don's device, so render the options with the
inline visual widget (show_widget, buttons call sendPrompt) or a private Artifact page, then build from his pick.

## Design toolkit installed
- superpowers (obra/superpowers): brainstorming, writing-plans, verification-before-completion
- impeccable (pbakaus/impeccable): /impeccable critique, audit, polish, animate, delight, overdrive
- Playwright MCP: real-browser checks of every page at phone and desktop sizes
