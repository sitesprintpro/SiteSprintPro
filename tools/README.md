# SiteSprintPro build kit

Builds and checks the public site. Not linked from the site.

- hub/build_hub.py: generates the hub pages. Edit CONFIG at the top, run it.
- src/<slug>.html: sample sources. Build: python3 inline.py src/hvac.html ../hvac/index.html
- preflight.py (ssp-design checks), mobile.py (four phones plus desktop), overview.py (one-glance page image)
- licenses/<slug>.csv: where every sample photo came from (Pexels License)
- BRIEF.md: the standard every sample was built to
